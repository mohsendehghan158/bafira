# بافیرا | BAFIRA — سایت تک‌صفحه‌ای معرفی برند

یک وب‌سایت تک‌صفحه‌ای (single page) برای معرفی برند بافیرا در حوزه تولید حوله و منسوجات
بافتنی. این سایت **فروشگاهی نیست**؛ هدف آن معرفی برند، محصولات، فرآیند تولید، شرایط
همکاری و راه‌های ارتباطی است.

محتوای محصولات، سایزها، ویژگی‌ها و متن معرفی برند (فارسی و انگلیسی) از روی بسته‌بندی
رسمی محصولات بافیرا نوشته شده است. پالت رنگ سایت هم همان زرد و مشکیِ بسته‌بندی است.

بافیرا در حال حاضر نماینده یا شعبه ندارد و فروش مستقیم از کارخانه انجام می‌شود؛ محتوای
سایت هم بر همین اساس نوشته شده است.

## اجرا

پروژه کاملاً استاتیک است و به هیچ ابزار بیلد یا وابستگی npm نیاز ندارد:

```bash
# باز کردن مستقیم فایل
xdg-open index.html

# یا اجرای یک سرور محلی ساده
python3 -m http.server 8000
```

سپس به آدرس `http://localhost:8000` بروید.

برای انتشار، کافی است محتوای همین پوشه روی هر هاست استاتیک
(GitHub Pages، Netlify، Cloudflare Pages، یا هاست اشتراکی) قرار بگیرد.

## ساختار فایل‌ها

```
index.html            کل صفحه؛ شامل اسپرایت آیکون‌های SVG و داده ساختاریافته JSON-LD
assets/css/styles.css توکن‌های طراحی، چیدمان و کامپوننت‌ها
assets/js/main.js     تعاملات: منوی موبایل، اسکرول، شمارنده‌ها، آکاردئون، فرم
assets/img/favicon.svg نشان برند
```

## بخش‌های صفحه

| بخش | شناسه |
| --- | --- |
| معرفی و شعار برند | `#hero` |
| سبد محصولات (۵ گروه محصول با سایزهای واقعی) | `#products` |
| شش ویژگی مشترک محصولات | `#why` |
| داستان برند و آمار | `#about` |
| فرآیند تولید در شش مرحله | `#process` |
| همکاری، خرید بدون واسطه و محدوده ارسال | `#partners` |
| نظرات مشتریان | `#testimonials` |
| سوالات متداول | `#faq` |
| تماس و فرم درخواست همکاری | `#contact` |

## شخصی‌سازی

**رنگ‌ها و اندازه‌ها** در بالای `assets/css/styles.css` به‌صورت متغیر CSS تعریف شده‌اند.
پالت از بسته‌بندی برند گرفته شده: `--yellow` زرد طلایی، `--ink` مشکی و `--cream` پس‌زمینه گرم.

**بافت پارچه‌ها** با `repeating-linear-gradient` ساخته شده‌اند و تصویر واقعی ندارند.
هر جا `<div class="swatch swatch--...">` می‌بینید می‌توانید آن را با `<img>` عکس واقعی
محصول جایگزین کنید. متغیر `--u` روی هر `.swatch` ضخامت راه‌راه‌ها را کنترل می‌کند.

**فونت** وزیرمتن از Google Fonts بارگذاری می‌شود. برای استفاده آفلاین یا سرعت بیشتر،
فایل فونت را داخل `assets/` قرار داده و لینک `<link>` را با `@font-face` جایگزین کنید.

## لوگو

نشان داخل `assets/img/favicon.svg` و سیمبل `#i-logo` در `index.html` یک **بازسازی تقریبی**
از لوگوی بافیراست، نه فایل اصلی. هر وقت فایل رسمی لوگو (ترجیحاً SVG) را داشتید، جایگزینش کنید:
محتوای `<symbol id="i-logo">` را با مسیرهای لوگوی اصلی عوض کنید و همان فایل را به‌عنوان
فاوآیکون هم بگذارید.

## مواردی که باید با اطلاعات واقعی جایگزین شوند

اطلاعات زیر در حال حاضر نمونه (placeholder) هستند:

- شماره تماس `۰۳۵-۳۵۰۰۰۰۰۰`، ایمیل `info@bafira.ir` و نشانی کارخانه
- لینک شبکه‌های اجتماعی در پاورقی (فعلاً `#`)
- شماره واتساپ در بخش «نمونه محصول می‌خواهید؟»
- نظرات مشتریان در بخش «آنچه خریداران می‌گویند» (متن‌ها نمونه‌اند)
- عکس محصولات؛ فعلاً بافت پارچه‌ها با CSS شبیه‌سازی شده است
- دامنه `bafira.ir` در تگ `canonical`، متاتگ‌های Open Graph و JSON-LD

## فرم تماس

فرم فعلاً هیچ درخواست شبکه‌ای ارسال نمی‌کند و فقط اعتبارسنجی سمت کاربر و پیام موفقیت را
نشان می‌دهد. برای فعال‌سازی، در `assets/js/main.js` داخل رویداد `submit` یک `fetch` به
اندپوینت مورد نظر خود اضافه کنید.

## دسترس‌پذیری و سازگاری

- ساختار کاملاً راست‌به‌چپ با `dir="rtl"` و چیدمان مبتنی بر ویژگی‌های منطقی CSS
- پشتیبانی از `prefers-reduced-motion` برای غیرفعال شدن انیمیشن‌ها
- لینک پرش به محتوا، برچسب‌های ARIA روی منو و دکمه‌ها، و حالت `:focus-visible`
- استایل چاپ برای گرفتن خروجی PDF از صفحه
